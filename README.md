# ai-toolkit

AI Tools

## Skills

- [`claude/skills/coding`](claude/skills/coding/SKILL.md) — Multi-language coding
  standards, layered: a top-level `SKILL.md` holds the universal principles (one
  class per file, small testable methods, adapter pattern at I/O boundaries,
  composition over inheritance, configuration-driven design), and `languages/*.md`
  files hold language-specific idioms and code examples for
  [`languages/ruby.md`](claude/skills/coding/languages/ruby.md),
  [`languages/python.md`](claude/skills/coding/languages/python.md), and
  [`languages/java.md`](claude/skills/coding/languages/java.md). Additional languages
  get their own file once there's a real codebase to draw the patterns from.
